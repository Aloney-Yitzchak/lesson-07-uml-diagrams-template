# 📐 UML Diagrams

הכנס לכאן את תרשימי ה-UML שלך / Place your UML diagrams here

## Required Files:
- `class-diagram-initial.png` — Class Diagram לפני הוספת priority
- `class-diagram-updated.png` — Class Diagram אחרי הוספת priority  
- `activity-diagram-initial.png` — Activity Diagram של addItem

## How to export from draw.io or Lucidchart:
1. File → Export As → PNG
2. Save the PNG file here in the `diagrams/` folder
3. `git add diagrams/`
4. `git commit -m "Add UML diagrams"`
5. `git push`
